# astrologer.ai UI Design System

Version 1.0

---

# Design Philosophy

The product should feel like:

Apple
+
Calm
+
Headspace
+
Modern AI

NOT

Traditional astrology websites.

Every screen should have lots of breathing room.

Every animation should feel intentional.

The website should feel expensive.

---

# Design Principles

1. One primary action per screen.

2. Large whitespace.

3. Dark premium theme.

4. Soft animations.

5. High readability.

6. Mobile-first.
